## Requirements 
- PHP installed (7.4+ or whatever version you are using
- Local server (XAMPP, MAMP etc) 
- Web browser 
 
## Installation 
1. Clone or download the repository. 
2. Place the project folder into your server's web root (e.g., htdocs/ for XAMPP) 
3. Start the server.
